# 部署建议

## 本地演示

适合比赛路演：一台带 GPU/Apple Silicon 的电脑 + USB 摄像头或视频文件。

## 校园/园区试点

优先复用已有 RTSP 摄像头，把推理服务部署在同一局域网的电脑/边缘主机：

```text
已有摄像头 -> RTSP -> AI 推理主机 -> Web 管理后台 -> 事件数据库/截图
```

## 安全注意

- 当前 Flask 启动方式是开发/试点服务，不建议直接暴露公网；正式部署使用反向代理与 WSGI 服务。
- `.pt` 权重本质上是序列化模型文件，只加载可信来源模型。
- RTSP 地址可能包含账号密码，正式部署不要截图/日志公开这些地址。
- 公共视频数据按最小必要原则保留，事件截图需要访问控制与留存策略。
